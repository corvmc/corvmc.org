## Band events

Owners and admins can create events for the band from the band's **Events** page —
a list of the band's shows with their status (draft, published, or cancelled).

## Creating an event

1. Open the band's **Events** page and choose **Create Event**.
2. Fill in the **title**, **date** and **start time** — that is all it asks.
3. Create it. The event's page opens next: add the end and doors times,
   **location**, **tags**, the bill, a poster and an external **ticket link**
   there, then **Save**.
4. New events start as drafts, so nothing is public until you publish.

## Managing an event

Opening an event takes you straight to its details, ready to edit — change
anything and choose **Save**. **More** holds the rest: **publish** it (make it
visible), **unpublish** it back to a draft, remove the poster, or **cancel** it.
Published events show up for the community.

If your band is only credited on someone else's bill — the **guest** tag on the
events list — you can see the listing but not change it. Ask the band that
created it.

Members who aren't admins see the same page, read-only.
