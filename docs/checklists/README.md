# checklists

Cross-cutting rollouts tracked to completion — a change applied tranche by tranche across the tree,
where the ordering and the decisions behind it outlive any one session.

Same rule as [`plans/`](../plans/): the reasoning lives here, the outstanding work lives in GitHub
Issues. A status column that is the only record of what is left cannot be searched, assigned, or
closed by the PR that finishes it.

The annotated table is in [`docs/README.md#checklists`](../README.md#checklists).
