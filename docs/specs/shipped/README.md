# specs/shipped

Archived specs. These features are live, so this directory answers **why** something is the way it
is — the options weighed and rejected while it was designed.

For **what** it does today, read
[development/business-workflows.md](../../development/business-workflows.md) or
[manual/](../../manual/README.md) instead. A shipped spec is not kept current with the code and will
drift; that is expected and is not a defect to file.

A spec lands here as the last step of the feature checklist. The annotated table is in
[`docs/README.md#specs`](../../README.md#specs).
