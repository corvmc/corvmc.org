# plans

Sequenced build plans — PR by PR — kept only while they track something still in motion.

A finished plan's content is either shipped, in which case git history is the record, or was filed
as an issue when the plan was retired. Nothing is owed to a plan that no longer has a live row.

**Status belongs in the tracker, not in the ledger.** A plan that carries the only copy of what is
still outstanding is invisible to `gh issue list`, which is where anyone actually looks. Keep the
reasoning here — why a step is ordered where it is, what was decided and rejected — and let the
remaining work be issues.

The annotated table is in [`docs/README.md#plans`](../README.md#plans).
