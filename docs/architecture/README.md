# architecture

How the system is wired, and the runbooks for operating it.

Start with [overview.md](overview.md) for the shape of the application, then
[domain-model.md](domain-model.md) for what the tables mean — three verticals over two horizontals,
and the shapes that recur across them.

The rest are runbooks rather than explanations: [operations-manual.md](operations-manual.md) for
day-to-day production, [deployment-checklist.md](deployment-checklist.md) for a first deploy, and
one file per integration that needs vendor-side setup a repo cannot perform for you.

The annotated table is in [`docs/README.md#architecture`](../README.md#architecture).
