# Calendar poster

Status: ✅ Built

**Print poster** in the Events header (`/staff/events/poster`, #3112) renders a month's public events (published, not meetings or committee sessions) in date order, each marked as a CMC or member event. A QR code links to the month on the public events page, and the footer carries the logos of the sponsors those listings credit. Staff pick Letter or Tabloid (PDF) or the social size (PNG), preview it and download it. Cloudflare Browser Rendering lays it out. See `docs/development/business-workflows.md#9-the-gig-guide-and-community-listings`.
