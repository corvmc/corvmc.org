# Suggestions

Status: ✅ /staff/suggestions

Board / Needs review / Hidden tabs over the member suggestion board, sorted by votes. Staff set a status and write one public response (a single action, so the member gets one notification), approve or reject posts from members on review, review proposed edits against a before/after of what members actually voted for, hide or restore, and merge duplicates — vote transfer is deduped, so a member who voted for both is counted once. A `planned` or in-progress gear request links to `/staff/inventory/intake`, and the arrival recorded there closes it. Reported suggestions are resolved in `/staff/flags`, not here: upholding hides the post and puts the author on review (`member_standing` at scope `suggestion`), dismissing restores it. Not flag-gated. See `docs/decisions/0036-one-report-takes-a-suggestion-off-the-board.md`
