# Venue access

Status: ✅ On /staff/venues/{id}

Three access answers on `venue` — step-free entry, accessible restroom, seating — each `yes`, `no` or `unknown`, with `unknown` the default and distinct from `no`. Staff set them in the venue's edit form; every public and member event page at that venue shows the known answers in its facts and nothing for `unknown` (#2717).
