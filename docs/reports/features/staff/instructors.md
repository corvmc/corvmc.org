# Instructors

Status: ✅ /staff/members?role=teacher

Who teaches in the practice room: the Members list's teacher filter (#2765). Applications lead the page — the only rows waiting on staff — then the roster, then those not currently teaching. Grant directly to a member you know, or approve an application; **sending one back is not a rejection** (`rejected` + `reviewNotes`, the member edits and resubmits, nothing deleted), which is the same return state `event.reviewNotes` and `volunteer_hour_log.reviewNotes` already use. Pause and retire both block booking and differ only in intent, and neither cancels future bookings — a booked lesson has a student who has been told a time. A read-only panel on the **Space** tab of `/staff/members/[id]`. See business-workflows §1, Teaching bookings
