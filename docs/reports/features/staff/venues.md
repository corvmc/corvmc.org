# Venues

Status: ✅ /staff/events?view=venues

Where a show is, as a row rather than as a sentence. `venue` (name deliberately not unique — `slug` carries that; address, capacity, contact, load-in notes, soft archive) plus `event_listing.venueId` **alongside** the free-text `event.location`, which is untouched and still the only thing a band listing has. The load-bearing column is `isPrimary`, held by exactly one row through a partial unique index and moved in a single `db.batch` because the clear has to land before the set: `holdsSpace()` reads it to answer the one question free text never could — does a show here hold the practice room? A blank venue reads as **yes**, which is what every event created before the table meant, so the backfill is the safe direction rather than a guess. Ticking _Reserve practice space_ for an off-site venue is refused by name rather than ignored, and the production console's Space Reservation card says _Off-site — {venue}_ instead of nagging for a hold that would be wrong — the one case its own comment admitted to getting wrong. Guarded as `event.read` / `event.manage` rather than a `venue.*` set of its own: there is no job here that curates rooms without producing in them, and a capability exists when a guard names it. `backline` and `links` from the spec are **not** built — no surface reads them yet.
