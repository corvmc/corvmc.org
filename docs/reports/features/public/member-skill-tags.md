# Member skill tags

Status: ✅ /member/profile + /member/directory

What a member can do besides play — sound engineer, photographer, promoter — as a fourth `directory_tag` kind, `skill`, which cost no migration. Set in the profile's Music card with suggestions from what members already typed; shown as a Skills tag cloud on both member profile pages (public carries it, like instruments); filterable on the member directory's Members tab through the same kind-scoped `tagCondition`, so a genre spelled the same cannot answer. Members only — a band's needs are `seeking_instrument`. A volunteer role lists the skill tags that suit it (`volunteer_role.skill_matches`, edited on the role's page), and a shift's Who to ask list ranks and flags candidates whose tags are on it (#1445). Seeded persona: `undecided@`. See `docs/architecture/domain-model.md`
