# Band sites (premium)

Status: ✅ {slug}.corvmc.org → /band-site/[slug]

Standalone microsites for premium bands: block-based page (14 block types, 7 themes, sanitized custom CSS). **The page arrives built, not blank** — `reconcileBlocks` in `src/lib/utils/band-site-preset.ts` projects the stored array into the full catalogue on read, at both the editor query and the public site query, so the column only gains the preset when the band saves. That is one projection instead of a hook on the Stripe sync _and_ the staff comp, and it reaches bands that were already premium. Legacy pages keep their own blocks, order, duplicates and spacers, with the missing types appended after them. The editor is therefore **reorder and hide, not add and delete**: `hidden` is optional on every block (no migration — `blocks` is JSON), `prepareBlocksForRender` drops hidden blocks so an unpublished `custom_html` never ships, and the renderer filters too because the editor's live preview feeds it the array being edited. Blocks with nothing to say render nothing, which is what lets the catalogue be complete without the page looking padded — hero and bio fall back to the band's own name and bio, so the preset itself holds no band content, events page, printable EPK, per-band robots.txt/sitemap.xml + OG meta, Turnstile-protected contact form emailing the booking contact (KV rate-limited). Subdomain reroute in `src/hooks.ts` (reserved slugs in `src/lib/reserved-slugs.ts`, base domain from `PUBLIC_SITE_URL`); wildcard zone routes in wrangler.toml. Block HTML sanitized at save + render (`js-xss` — replaced the no-op DOMPurify+linkedom setup); rider/stage-plot uploads accept PDF.
