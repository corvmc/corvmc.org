# Press kit

Status: ✅ /band/[slug]/press-kit + /api/bands/[id]/press-kit.zip

**Free for every act**, and the reason `/directory/bands/{slug}` is itself the EPK. Three surfaces from one `band_site.epk` column, split by audience in `src/lib/server/band/press-kit.ts` — the only module allowed to project it. PUBLIC (`publicPressKit`): press quotes, highlights, press photo, video; rendered on the directory profile with a print stylesheet, so the page a booker browses is the one that prints. PACKAGE (`fullPressKit`): booking/management/press contacts with phone numbers; reached only through the admin-guarded zip, which holds a self-contained one-pager (`press-kit-html.ts`, images by zip-relative path so it opens offline), a plain-text version, full-resolution photos, and a QR back to the live page. **No contact detail of any kind is published** — `submitBandContactForm` (Turnstile + KV rate limit, `band-contact.remote.ts`) is the only route in, and since band chat it opens a thread in the act's own inbox rather than emailing an address (see the row above). `FREE_PRESS_PHOTOS` caps the free gallery at one, server-enforced in the media route; premium adds video and lifts the cap. It carries nothing technical — an EPK is a booking document, and what an act needs on stage is the tech rider's, which models it properly. `epk-completeness.ts` scores eleven named rungs on the dashboard and the editor — the shows rung fills itself from the gig guide.
