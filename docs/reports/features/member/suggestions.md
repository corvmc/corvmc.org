# Suggestions

Status: ✅ /member/suggestions

Member suggestion board for anything about the collective (gear, programming, the space, policy, the website), with one upvote per member per suggestion and a public staff response. Posts publish immediately. Members can report a suggestion, which pulls it off the board pending staff review; an upheld report puts the author's future suggestions through review first. Authors edit their own freely until someone else votes, after which an edit becomes a request staff approve — closing the bait-and-switch where a popular suggestion is rewritten after collecting votes. Not flag-gated. See `docs/decisions/0037-suggestion-edits-lock-at-the-first-outside-vote.md`
