# Teaching

Status: ✅ /member/profile

One card, five states: apply · awaiting review · sent back with the note and an edit-and-resubmit · the listing editor · a status line when paused or retired. The application **is** the draft listing, so staff approve exactly what they would publish — there is no second form. An approved instructor gets Teaching under **For** on the booking form (#3029), which books on teaching terms: its own rate, duration floor, advance window and settlement. They also get their own accepting-students switch, which is distinct from staff pausing them. Teaching time is **$5/hr — the rate a sustaining contribution already buys, with the monthly cap lifted**, not a discount on the $15 drop-in rate; credits apply normally because at $5/hr one credit is exactly one half-hour slot
